# Weekly Update: 2026-W37 - Posts, AI Media, and LinkedIn Publishing

## Overview

This update introduces a complete short-form Posts workflow and expands LinkedIn publishing from plain text into a media-capable distribution studio. It also moves the new AI behavior into the Prompt Library so generation can be improved without code changes.

## Key Features

### 1. Public Posts and Admin Studio

- Added a paginated `/posts` feed for published short-form content.
- Added admin pages to create, edit, publish, archive, filter, and delete posts.
- Added dedicated LinkedIn composition pages for both posts and articles.
- Added responsive admin layouts and scroll behavior for smaller and Windows viewports.

### 2. AI Post and Image Generation

- Added topic, tone, and instruction-based post generation.
- Generated content is saved as an editable draft and never auto-published.
- Added post image generation and regeneration grounded in the post's title, body, and tags.
- Added 4:5 generated images with Firebase Storage lifecycle cleanup.

### 3. Rich LinkedIn Publishing

- Added text, image, and document/carousel publishing modes.
- Added optional images for individual carousel slides.
- Added a bulk action to generate every missing image.
- Grounded LinkedIn captions, images, and slides in the source article or post.
- Moved remote image fetching to the server to avoid browser CORS failures.
- Improved expired-token handling and the reconnect workflow.

### 4. Prompt Library Coverage

- Added editable `post.generate` and `post.image` templates.
- Organized LinkedIn caption, source context, rich media, image, and slide-image templates under the LinkedIn category.
- Disabled stale prompt catalog caching so new defaults appear in the admin library immediately.
- Kept runtime prompt overrides in ignored `prompts.json`, with shareable defaults in `prompts.example.json`.

## API and Data Changes

- Added the `/api/v1/posts` CRUD, generation, image generation, and publication endpoints.
- Added the `/api/v1/integrations/ai-post/image` generation endpoint.
- Replaced the legacy LinkedIn sync flow with `/api/v1/integrations/linkedin/post` for text, image, and document posts.
- Added Firestore indexes for post feed and owner/status queries.

## Quality and Reliability

- Added server coverage for post authorization, validation, generation, prompt usage, and generated-image cleanup.
- Verified the client with TypeScript checks and a production Next.js build.
- Kept uploaded and generated media ownership isolated by user.

## What's Next

- Add more social platforms to the dedicated post distribution page.
- Add scheduling, publication history, and delivery analytics.
- Add reusable visual themes for generated posts and carousel decks.
