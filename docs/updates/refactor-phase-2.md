# Refactor Update: Phase 2 - Enhanced Identity & Content Management

## Summary
This update introduces significant improvements to how users manage their professional identity and content on TaughtCode. Key focus areas include granular experience management, GitHub-integrated project selection, and standardized Markdown support.

## Key Features

### 1. Granular Experience Management
Users will be able to add, update, and delete individual experience entries with dedicated endpoints, ensuring better data integrity and a smoother UI experience.

### 2. GitHub Project Sync
Instead of just viewing GitHub stats, users will be able to browse their repositories and select specific ones to feature on their profile. These "Featured Projects" can be enhanced with custom descriptions, tags, and images.

### 3. Article Deletion & Cleanup
Full support for article deletion will be ensured, including the automatic removal of associated assets from cloud storage.

### 4. Markdown Everywhere
All description fields will support Markdown input, allowing for rich formatting in bios, project summaries, and experience details.
